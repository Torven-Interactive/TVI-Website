File Structure

Files must reflect what is shown in the base game.
Never modify the base game jsons! 

📁 Mod Name/
│
📁 definitions/
├── 📄 mesh.json                <-- Monolithic 2D/3D topological vertex grids & cellular lattices
📁 biomes/
└── 📄 [tag]_[name].json             <-- Global climate specifications and color matrices
📁 cultures/
└── 📄 [tag]_[name].json          <-- Ethnic tradition trees, weights, and heritage indexes
📁 religions/
└── 📄 [tag]_[name].json          <-- Global faith organizations and spiritual layout blocks
📁 name bases/
└── 📄 [tag]_[name].json          <-- Linguistic syllable structures for territory names
📁 burgs/
└── 📄 [tag]_[name].json          <-- Individual urban center sheets stripped of visual mesh nodes
📁 states/
└── 📄 [tag]_[name].json          <-- Sovereign nation configurations stripped of raw boundary arrays
📁 provinces/
└── 📄 [tag]_[name].json          <-- Sub-state regional profiles and localized demographics
📁 rivers/
└── 📄 [name].json               <-- Hydrological systems, width indexes, and discharge factors
📁 routes/
└── 📄 [group]-[id].json         <-- Commercial infrastructure paths and vector connections
📁 markers/
└── 📄 [type]-[id].json          <-- Interactive point-of-interest indicators (mines, ruins, dens)
📁 zones/
└── 📄 [name]_[id].json          <-- Macro climate bands and environmental boundary regulations
